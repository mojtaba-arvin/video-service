# Commit identity and attribution policy

For maintainer-directed AI-assisted implementation, use Git author \`Mojtaba Arvin <m.arvin@live.com>\` only after confirming this exact email is verified on the maintainer's GitHub account. Do not use model, assistant, AI-agent, Copilot, Claude, Cursor, Codex, Gemini, generic agent, or bot identities as the author. Do not add bot/AI \`Co-authored-by\` trailers.

Include \`<!-- maintainer-directed-ai-work -->\` in the PR body for owner-authorized AI-assisted work. This machine-readable marker requires every commit author to match the maintainer identity. Disclose AI assistance in the PR description; the marker does not claim the maintainer personally typed every line.

Preserve every real human contributor's original author name/email. Never relabel another person as the maintainer and never rewrite historical commits.

Genuine GitHub Actions/Dependabot automation may author a commit only when the commit was actually generated by that automation and the PR has the explicit \`allow-automation-commits\` label. This exception does not cover agent-written implementation. Bot co-author trailers remain prohibited. A \`web-flow\` committer is distinct from the commit author.

Convenience defaults (not enforcement):
\`\`\`sh
git config --global user.name "Mojtaba Arvin"
git config --global user.email "m.arvin@live.com"
\`\`\`

\`scripts/check_commit_identity.py\` checks all PR commits, rejects bot/agent authors and bot co-author trailers, permits known automation only with the explicit label, and enforces the maintainer identity when the marker is present. The \`Commit identity\` workflow uses read-only GitHub permissions and checks out only trusted base-branch code. Configure this check as required in branch protection/rulesets where governance permits; a workflow alone does not block merges.

Git metadata is self-asserted: validation cannot prove who physically typed code or detect every disguised agent identity. Verify the email association and disclose AI assistance transparently.
